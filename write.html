はじめの準備（1回だけ）

このページから GitHub に保存できるように、「書きこみ用の鍵」を作って、ここに貼ります。鍵は、この端末の中だけに保存されます。

  1. GitHub にログインした状態で 鍵を作る画面 を開く
  2. Token name はなんでもOK（例：oc-archive-write）。Expiration は好きな期限（切れたら作りなおす）
  3. Repository access で「Only select repositories」を選んで、サイトのリポジトリを1つだけ選ぶ
  4. Permissions の「Repository permissions」で、Contents を「Read and write」にする
  5. いちばん下の Generate token を押して、出てきた「github_pat_…」をコピーして、下に貼る

※ 鍵は人に見せないでね。この端末をなくしたときは、GitHub の同じ画面から鍵を消せば大丈夫です。
